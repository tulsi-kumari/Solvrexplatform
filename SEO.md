# Solvrex — SEO & Discoverability

Reference for the implemented SEO. Titles/descriptions live in code (per-page
`metadata` via `lib/seo.ts → pageMetadata`); structured data via `lib/seo.ts` builders +
`components/JsonLd`; sitemap/robots via `app/sitemap.ts` / `app/robots.ts`; icons + OG
image are generated (`app/icon.svg`, `app/apple-icon.tsx`, `app/opengraph-image.tsx`).

## Part 8 — Article templates (outlines only)

1. **How To Tailor Your Resume For Every Job Application** — slug `how-to-tailor-your-resume`
   - Primary: how to tailor resume · Secondary: ats friendly resume, resume keywords, resume customization
   - Outline: Why generic resumes fail → Read the JD (keywords, must-haves) → Mirror language (ATS) → Tailor summary & top bullets → Quantify impact → Formatting that parses → Before/after example → Checklist.
2. **LinkedIn Profile Optimization Checklist** — slug `linkedin-profile-optimization-checklist`
   - Primary: linkedin optimization · Secondary: linkedin headline, recruiter visibility, linkedin keywords
   - Outline: How recruiters search LinkedIn → Headline → About → Experience bullets → Skills & keywords → Photo/banner → Activity/social proof → Full checklist.
3. **How To Ask For Referrals Without Sounding Desperate** — slug `how-to-ask-for-referrals`
   - Primary: how to ask for referrals · Secondary: referral outreach, networking for jobs, referral message template
   - Outline: Why referrals convert → Who to ask → Warm vs cold → Message templates → Make it easy (role + resume) → Follow-up etiquette → What not to do.
4. **Job Search Planning Framework** — slug `job-search-planning-framework`
   - Primary: job search plan · Secondary: job search strategy, weekly job search routine, target companies
   - Outline: Treat it like a project → Define targets → Channels & ratios → Weekly cadence → Tracking system → Reviewing & adjusting → Template.
5. **Interview Preparation Checklist** — slug `interview-preparation-checklist`
   - Primary: interview preparation checklist · Secondary: behavioral interview prep, technical interview prep, STAR method
   - Outline: Before (research, stories, logistics) → STAR stories → Common questions → Questions to ask → During → After/follow-up → Checklist.
6. **Why Job Applications Get Rejected** — slug `why-job-applications-get-rejected`
   - Primary: why job applications get rejected · Secondary: ats rejection, resume mistakes, application tips
   - Outline: ATS filtering → Generic resume → Keyword mismatch → Over/under-qualified signals → No referral → Timing/volume → Fixes for each.
7. **How Recruiters Actually Read Resumes** — slug `how-recruiters-read-resumes`
   - Primary: how recruiters read resumes · Secondary: six second resume, resume scanning, recruiter screening
   - Outline: The 6-second skim → What they look at first → Top-third real estate → Titles/companies/dates → Red flags → Structure to match → Takeaways.
